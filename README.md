# chuanxin-update

> 传信 · 版本信息发布仓库

## 简介

本仓库用于托管 **传信** 应用的版本信息，仅包含版本号及相关元数据，应用源码不开源。

客户端可通过读取本仓库的版本文件，实现以下能力：

- 检测是否有新版本可用
- 获取最新版本号及更新说明
- 引导用户前往下载更新

## 版本信息

最新版本请查看 [VERSION](./VERSION) 文件（或仓库中的版本记录文件），每次发布新版本时会同步更新。

## 版本发布流程

1. 在仓库中更新版本号文件
2. 基于该版本创建对应的 Git Tag（格式：`vX.Y.Z`）
3. 创建 Release 并填写更新说明（changelog）

## 相关说明

- 本仓库**仅包含版本信息**，不包含任何应用源代码
- 如需反馈问题，请通过 [Issues](../../issues) 提交，并注明遇到问题的应用版本号

## 许可

版本信息仅用于传信应用更新服务，未经授权请勿转载或用于其他用途。
